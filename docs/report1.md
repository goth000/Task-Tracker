## 1. Краткое описание задачи и среды выполнения

### 1.1 Постановка задачи

Разработать консольное приложение на C++, которое:

- считывает и валидирует JSON-файлы с задачами;
- выполняет CRUD-операции (создание, чтение, обновление, удаление);
- поддерживает фильтрацию по группам;
- формирует отчёт по просроченным задачам;
- генерирует тестовые JSON-файлы (до **100 000**) с корректными и ошибочными данными.

### 1.2 Среда выполнения

| Параметр | Значение |
|--------|---------|
| **ОС** | Linux / Windows / macOS |
| **IDE** | Visual Studio Code / CLion / Visual Studio 2022 |
| **Компилятор** | GCC 12+ / Clang 14+ / MSVC 2017+ |
| **Стандарт C++** | C++17 |
| **Библиотеки** | Standard Library (без внешних зависимостей) |
| **Флаги компиляции** | `g++ -std=c++17 -O2 -o task_tracker main.cpp` |

3. Описание ключевых алгоритмов
```
3.1 Валидация данных
Функция isValidDate(day, month, year) проверяет:

диапазоны дат;

корректность дней в месяцах;

високосные годы.

Возвращает true, если дата валидна, иначе false.
```

3.2 Парсинг JSON
```
void readFile(const string& name, vector<task>& list);
```
Алгоритм:
```
Построчное чтение файла

Поиск ключей: id, title, due, priority, group, done

Извлечение значений между кавычками

Экранирование (\", \\, \n)

Обработка ошибок через stderr

Добавление валидных задач в контейнер
```
3.3 Фильтрация и отчёты
Фильтрация по группе

```
O(n) — линейный поиск
├── поиск задач с group == searchGroup
└── вывод результата
```
Поиск просроченных задач


├── сравнение дат YYYY-MM-DD
├── done == false
├── due < today
└── вывод с подсчётом
3.4 Генератор тестовых данных

```
void generateTaskJsonFiles(int fileCount, int errorPercent);
```
Процесс генерации:

создание от 1 до 100 000 файлов;

10–100 задач в каждом;

errorPercent — вероятность создания ошибочной задачи.

Типы ошибок
```
№	Тип	Пример
1	Пустой title	"title": ""
2	Невалидная дата	"due": "2026-13-45"
3	Неверный приоритет	"priority": "URGENT"
4	Пустая группа	"group": ""
5	Полностью битая	Все поля некорректны
```

5. Обработка ошибок и UX
```
Таблица ошибок
Ошибка	Реакция	Сообщение
Файл не найден	Предупреждение	Не удалось открыть файл
Невалидная дата	Пропуск	Ошибка JSON
Неверный приоритет	Повтор ввода	Допустимо: low/mid/high
Пустой список	Блокировка	Список задач пуст
```
Консольное меню
```
1 - создать задачу
2 - удалить задачу
3 - изменить задачу
4 - фильтр по группе
5 - отчёт о просроченных
6 - просмотр всех задач
7 - режим разработчика
другое - выход
```
